# Foundational AI Questions
Filosofía
1. ¿Pueden utilizarse reglas formales para extraer conclusiones válidas? 
    (Can formal rules be used to draw valid conclusions?)
2. ¿Cómo emerge la mente a partir de un cerebro físico? 
    (How does the mind arise from a physical brain?)
3. ¿De dónde viene el conocimiento? 
    (Where does knowledge come from?)
4. ¿Cómo conduce el conocimiento a la acción?
    (How does knowledge lead to action?)
---
Matemáticas
1. ¿Cuáles son las reglas formales para extraer conclusiones válidas?
    (What are the formal rules to draw valid conclusions?)
2. ¿Qué se puede computar? 
    (What can be computed?)
3. ¿Cómo razonamos con información incierta? 
    (How do we reason with uncertain information?)
--
Economía
1. ¿Cómo debemos tomar decisiones para maximizar el beneficio?
    (How should we make decisions so as to maximize payoff?)
3. ¿Cómo debemos hacer esto cuando otros no cooperan?
    (How should we do this when others may not go along?)
5. ¿Cómo debemos hacer esto cuando el beneficio puede ser lejano en el futuro?
    (How should we do this when the payoff may be far in the future?)
