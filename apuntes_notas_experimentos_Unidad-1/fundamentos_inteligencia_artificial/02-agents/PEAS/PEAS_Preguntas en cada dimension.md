# Performance (Rendimiento)
**Determina cómo se medirá el éxito o el fracaso del agente.**

¿Cuál es el objetivo final que debe alcanzar el agente?
¿Qué métricas cuantitativas determinan 
si el agente lo está haciendo bien?
¿Cómo se castigan los errores, retrasos o el consumo excesivo de recursos?
¿Se prioriza la velocidad, la seguridad, la precisión o el bajo costo?

# Environment (Entorno)
**Define el mundo, contexto o espacio físico/virtual donde opera el agente.**

¿El entorno es estático o cambia de forma constante mientras el agente decide?
¿Es completamente observable mediante los sensores o hay información oculta?
¿Las acciones del agente tienen un efecto determinista o interviene el azar?
¿El entorno es discreto (como el ajedrez) o continuo (como manejar un auto)?
¿Existen otros agentes (competidores o colaboradores) interactuando 
en el mismo espacio?

# Actuators (Actuadores)
**Identifica las herramientas o mecanismos que usa el agente para interactuar 
y modificar el entorno.**

¿Qué acciones físicas o lógicas puede ejecutar el agente?
¿Qué extremidades, motores, pantallas o comandos de software tiene 
a su disposición?
¿Cómo se transmiten las decisiones del agente al mundo
real o virtual?
¿Cuáles son los límites físicos o operativos de estos mecanismos?

# Sensors (Sensores)
**Establece los canales de entrada por los cuales el agente percibe 
y recopila información del entorno.**

+¿Qué datos del entorno necesita conocer el agente para tomar decisiones 
correctas?
+¿Qué dispositivos (cámaras, radares, teclados, micrófonos, APIs)
capturan esa información?
+¿Los sensores proveen datos precisos o la información incluye ruido
y lecturas erróneas?
+¿Con qué frecuencia se actualizan las lecturas 
de estos sensores?
